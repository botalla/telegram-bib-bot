le but de ce projet est de faire bot telegram
le bot telegram va tourner sur google cloud
il va utiliser les api gemini pour repondre a des questions en language naturel.
il va utiliser mon API python qui se connecte avec le site de la bibliotheque de Paris dont voici le lien https://github.com/botalla/parisbibpy

les uses cases sont les suivants:
- lancer telegram depuis mon telephone et demander au biblio bot:
-- quels sont les livres a rendre aujourd'hui dans cette bibliotheque 
-- prolonge ce livre
-- prolonge tout ce qui expire dans moins de X jours
-- liste tout les emprunts de Camille
-- affiche les couvetures des livres a rendre etc.
